# GitHub packaging

## Included

Commit source code, requirements, documentation, supplied government CSV / OSM graph, compact final reports and figures, OD coordinates, convergence diagnostics and forward-search validation evidence. The active processed risk CSV is already tracked with Git LFS through .gitattributes.

## Local reproducible files

.gitignore excludes IDE settings, caches, bytecode, environments, Bayesian backups/candidate duplicates, the full posterior-rate CSV and large per-OD route/comparison CSVs. These are regenerated by the documented scripts. Compact posterior summaries and an 08:00 sample are included so readers can inspect the model without downloading all intermediate data.

GitHub warns above 50 MiB and blocks normal Git files above 100 MiB; use [Git LFS](https://docs.github.com/en/repositories/working-with-files/managing-large-files/about-large-files-on-github) for the active risk CSV. Do not add duplicate score CSVs outside its LFS rule.

## Review before upload

```bash
git lfs version
git lfs pull
git status --short
git diff --stat
git diff --check
```

Review the changed files, then stage the intended repository changes, commit and push through your usual Git workflow. This cleanup does not commit, push or rewrite Git history. Ordinary source/results updates do not require history migration; any existing large non-LFS blobs in history would need a separately reviewed migration.

## Reproduction order

Install requirements; optionally rebuild Bayesian scores; run the final benchmark; run sensitivity; generate sample routes. Model and OD hashes are recorded in metadata. Full results use 08:00 and equal OD weights, with final balanced 0.8/0.2. The original 50-OD trial and old model results are not part of final presentation.
